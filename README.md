# earl-greylyn

An [earl-grey](https://earl-grey.halt.wtf) colorscheme variant for Neovim. The light variant is `earl-greylyn`. The dark variant is `london-fog`.

## Usage

It's primitive and manual for now:

- Copy `earl-greylyn.lua` and `london-fog.lua` into `~/.config/nvim/colors`
- Add one of the following to your `init.lua` or other config file:
  - `vim.cmd("colorscheme earl-greylyn")`
  - `vim.cmd("colorscheme london-fog")`
